# Task Manager

A full-stack task management application built with Angular and ASP.NET Core.

## Technology Stack

- Angular 22
- C# / ASP.NET Core 10
- PostgreSQL
- Entity Framework Core
- WeatherAPI

## Project Status

Under active development.

The application is being developed incrementally using feature branches and pull requests.

## Architecture

The application separates frontend, API, application logic, domain logic, and infrastructure concerns.
